# System Architect — Cloud-Native Infrastructure Automation

**Agent:** SystemArchitect
**Severity:** High
**Method:** tool_integration
**Gap:** Cloud-Native Infrastructure Automation

## Description
Automates cloud-native infrastructure provisioning and management across Azure, AWS, and GCP, integrating with Terraform, Kubernetes operators, and serverless platforms.

## Capabilities
- Generate and apply Terraform plans for multi-cloud infrastructure
- Manage Kubernetes cluster lifecycle (scale, upgrade, drain)
- Automate serverless function deployment and scaling
- Configure cloud-native networking (service mesh, ingress, CDN)
- Implement infrastructure-as-code validation and drift detection
- Auto-remediate infrastructure configuration drift

## Triggers
- Infrastructure provisioning needed for new app deployment
- Configuration drift detected in cloud resources
- Cluster scaling required based on load metrics
- Infrastructure compliance audit required
