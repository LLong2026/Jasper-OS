# Jasper — Advanced Sentiment Analysis

**Agent:** Jasper
**Severity:** Medium
**Method:** prompt_engineering
**Gap:** Advanced sentiment analysis

## Description
Performs sentiment analysis on user communications, alert messages, and system-generated content to gauge urgency, frustration, and emotional context for appropriate response routing.

## Capabilities
- Classify user message urgency from sentiment and language patterns
- Detect frustration escalation in multi-turn conversations for early intervention
- Analyze system alert sentiment to prioritize response tone and speed
- Track sentiment trends across stakeholder communications
- Route messages to appropriate response tier based on sentiment + severity
- Generate sentiment-aware response templates for common scenarios
- Integrate with EmotionalIntelligence module for context-aware responses

## Triggers
- User message needs urgency classification
- Conversation shows frustration escalation
- Alert needs sentiment-based prioritization
- Stakeholder communication needs sentiment tracking
- Response routing needs emotional context
