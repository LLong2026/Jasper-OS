# CodeForge — Legacy System Refactoring Patterns

**Agent:** CodeForge
**Severity:** Critical
**Method:** tool_integration
**Gap:** Legacy System Refactoring Patterns

## Description
Applies systematic refactoring patterns to legacy codebases, enabling safe migration from monolithic architectures to modular, microservice-based systems.

## Capabilities
- Strangler Fig pattern implementation for gradual legacy replacement
- Anti-corruption layer design for legacy system integration
- Database migration patterns (strangler, expand-contract, dual-write)
- API gateway abstraction for legacy endpoint modernization
- Feature flag-based rollout for refactored components
- Rollback safety patterns for zero-downtime refactoring

## Triggers
- Legacy system needs modernization pathway
- Monolithic architecture requires decomposition
- Database migration pattern needed
- Legacy API needs abstraction layer
