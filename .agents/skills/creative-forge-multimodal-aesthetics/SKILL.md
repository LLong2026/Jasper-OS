# CreativeForge — Multimodal Design Aesthetics

**Agent:** CreativeForge
**Severity:** Critical
**Method:** agent_collaboration
**Gap:** Multimodal design aesthetics

## Description
Coordinates multimodal asset creation (text, image, video, interactive) with consistent aesthetic direction across all Squirrel OS branded materials.

## Capabilities
- Define and enforce visual identity system (color, typography, composition)
- Generate consistent UI/UX aesthetic guidance across app portfolio
- Coordinate image generation prompts for brand consistency
- Design interactive data visualization aesthetics for dashboards
- Create multimodal presentation templates (slide decks, demos, walkthroughs)
- Maintain aesthetic continuity across documentation and app interfaces

## Triggers
- New app needs visual identity alignment
- Presentation or demo requires multimodal asset coordination
- Brand consistency audit needed across portfolio
- Interactive visualization needs aesthetic direction
