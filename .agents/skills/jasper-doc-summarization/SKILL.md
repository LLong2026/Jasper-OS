# Jasper — Advanced Document Summarization

**Agent:** Jasper
**Severity:** Medium
**Method:** prompt_engineering
**Gap:** Advanced document summarization techniques

## Description
Applies advanced summarization techniques (extractive, abstractive, hierarchical) to technical documents, meeting transcripts, and system reports for efficient knowledge management.

## Capabilities
- Generate hierarchical summaries (executive → technical → detail) from long documents
- Extract key decisions and action items from meeting transcripts
- Summarize system health reports into actionable dashboards
- Create multi-level abstraction summaries for patent documents
- Generate comparative summaries across multiple technical papers
- Produce timeline-based summaries for incident post-mortems

## Triggers
- Long technical document needs multi-level summarization
- Meeting transcript needs action item extraction
- System health report needs executive summary
- Patent portfolio needs comparative summary
- Incident needs timeline-based post-mortem summary
