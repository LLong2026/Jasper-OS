## Patent Filings

### 1. METHOD, SYSTEM, AND APPARATUS FOR DETERMINISTICALLY GOVERNED PROBABILISTIC NEURAL COMPUTATION
| Field | Value |
|---|---|
| Patent Center # | 79313110 |
| Application # | 64/119,191 |
| Receipt Date | July 25, 2026 |
| Type | Provisional |
| Status | Filed |

**What it covers:**  
The foundational architecture of the JasperOS neural mesh — a system where a large language model (LLM) serves as the compute engine for a neural network topology, rather than as a component of one. Key innovations include:

- **LLM-as-Compute-Engine** — the LLM performs forward propagation through the mesh; it IS the processor, not a node
- **Entity-Persisted Topology** — neural network weights and connections stored as database entity records (not in-memory tensors), surviving restarts and distributed across apps
- **Deterministic Governance Boundary** — a validation layer that intercepts all probabilistic LLM outputs and validates them against invariant contracts before execution
- **Self-Healing as Training Data** — every healing event feeds back into the neural mesh as a learning signal, adjusting node weights and confidence scores
- **Bifurcated Proposal-Validation Model** — LLMs propose; the deterministic engine disposes. No probabilistic output reaches production without validation.

**Live implementation:** 31-node starter mesh across 5 layers deployed on Gabriel Superagent, 37 apps connected, 297 healing events at 100% success rate.

| Receipt Date | June 19, 2026 |
| Type | Provisional |

**What it covers:**  
A multi-rail payment settlement fabric that enables a single ISO 20022 financial message to route to, settle on, and receive confirmation from multiple blockchain networks simultaneously. Key innovations include:

- **Universal Rail Abstraction** — single API surface that maps to Lightning Network, XRP Ledger, Stellar, Algorand, and Ethereum settlement rails

## The Unified Architecture

These 7 patents are not independent inventions — they form an integrated stack:

```
LAYER 4: AI GOVERNANCE
├── Patent 64/119,191 — Neural Mesh (HOW the AI thinks)
└── Patent 64/114,746 — Jasper Hypervisor (HOW the AI is governed)

LAYER 3: FINANCIAL INFRASTRUCTURE
├── Patent 64/094,360 — ISO 20022 Bridge (HOW messages flow across rails)
└── Patent 19/693,343 — RL Token Minting (HOW tokens are issued)

LAYER 2: BLOCKCHAIN PRIMITIVES
├── Patent 64/082,606 — Satoshi Anchoring (HOW data is anchored to Bitcoin)
└── Patent 64/081,490 — ThreadZero (HOW assets transfer without gas)

LAYER 1: COMPUTATIONAL FOUNDATION
└── Patent 64/081,911 — Topological File Engine (HOW data is reconstructed)
```

The AI governance layer (Jasper, Gabriel, Amelia) supervises the financial infrastructure layer. The financial infrastructure uses the blockchain primitives for settlement and anchoring. The blockchain primitives rely on the computational foundation for data handling.

This is a complete, vertically integrated fintech AI stack — from data representation to AI governance.
